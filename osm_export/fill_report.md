# 高德 POI 补全报告：把 46 栋缺失建筑补进真实地图

> 生成日期：2026-09-25　数据源：高德开放平台 Web 服务 API（POI 搜索 + 地理编码）　配套：`compare_report.md`（OSM 对比报告）
> 本次仍只产出数据，**未改动 main.c / map.txt**。

## 一、为什么要做 GCJ-02 → WGS84 换算

高德返回的是 **GCJ-02（火星坐标）**，OSM 是 **WGS84**。实测这批数据两者相差 **平均 604 m（603~604 m）**——不换算会把所有补点建筑整体平移约 600 m，直接废掉。本流程已用标准算法逐点转换后再合并。

## 二、查询策略与结果

对每个缺失建筑依次尝试：① 地理编码（`江西省南昌市江西师范大学瑶湖校区`+名称）→ ② POI 搜索（`江西师范大学`+名称）→ ③ POI 搜索（名称）
并且**严格校验**：返回名称/地址必须包含目标关键词（避免地理编码悄悄回退到「校门」），坐标必须落在校区内或 400 m 缓冲内。

- 查询项：**44** 项；命中 **37** 项（其中高置信 32）；无直接命中 **7** 项（另有 3 项结果被剔除或去重）
- 剔除 2 项「疑似他校」结果：学术报告厅（只返回隔壁江西水利电力大学）、游泳池（只返回隔壁江科游泳馆）
- 去重 1 项：国际交流中心 与 OSM 已收录的「白鹿会馆（国际交流中心）」重复，已去重

## 三、合并结果

| 来源 | 数量 | 说明 |
|---|---|---|
| OSM 实测轮廓 | 32 | 真实多边形轮廓（宿舍 1~19 栋、5 个食堂、体育馆群等） |
| 高德 POI 定位 | 33 | 用 POI 经纬度定位，轮廓沿用原手绘形状并按 1/2.36 线性缩放以接近真实尺度 |
| 中轴线推断 | 3 | 正大坊、升旗台、校训墙 |
| **合计** | **68** | 另含 168 段 OSM 校内道路（步道/支路/台阶） |

比例缩放说明：上一轮实测现有地图建筑占地中位数是真实值的 **5.58 倍**，故线性缩放取 √5.58 ≈ **2.36**，让补点建筑与 OSM 实测轮廓视觉一致（可在生成脚本里调这个系数）。

## 五、使用与注意事项

1. 预览：备份现有 `map.txt` 后，把 `map_full.txt` 复制过去命名为 `map.txt` 即可（纯数据替换）；
2. 高德仅是**点数据**，没有建筑轮廓：补点建筑的形状来自原手绘图，只保证位置真实；
3. 高德 POI 存在**改名/搬迁滞后**（例如「长胜园三食堂」「芒果青年二食堂」是商业冠名），教学行政楼已用「江西师范大学瑶湖校区+楼名」的地理编码交叉验证；
4. 许可：OSM 部分为 ODbL（见 `NOTICE.txt`）；高德数据版权归高德，**仅建议学习/内部演示使用**，对外发布前请确认高德开放平台服务条款；
5. 仍有 7 项未解决（校史馆、学术报告厅、游泳池、风雨球馆、室内运动场、弘冠、新年广场），建议后续用卫星/航拍影像补描或现场采集。
